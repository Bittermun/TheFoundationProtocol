# A recurring offline edition for one collection

Would you authorize a maintained Markdown collection for a two-edition trial with an offline library? Your staff would continue editing the existing source. A build on the publisher's side would verify that each new archive is searchable, sign the update, and make it available to the library through the same channel.

The local demonstration starts with a field guide, replaces its source with a new edition, and confirms the new text through the recipient's Kiwix search. Repeating the source creates no additional edition. An invalid build leaves the accepted edition available.

For the trial I’d ask you to name one collection, confirm permission to publish it offline, and identify the person who can approve each source revision. The host operator would pin your public key and refresh a dedicated catalog. We would test whether the next two routine edits appear in the library and record how many manual steps the publisher and host needed for each.
