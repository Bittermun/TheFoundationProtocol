# The Foundation Protocol (TFP) — Ubiquitous Language Glossary

Canonical domain terminology across `tfp_core_v4`, `tfp_client`, `tfp_transport`, `tfp_security`, `tfp_demo`, and legacy `tfp_core`. Before introducing new table names, classes, functions, or API fields, align with these definitions so prose and code use **one crisp domain term**.

| Domain Term | Canonical 1-Sentence Definition | Canonical Code Symbol / Table |
| :--- | :--- | :--- |
| **Bulletin** | A versioned, Ed25519-signed off-grid emergency notice or knowledge update identified by `(bulletin_id, revision)` and governed by monotone admission rules. | `TFPNode.store_bulletin` (`tfp_core_v4/node.py`), `bulletins` SQLite table, `prepare_bulletin_package` (`tfp_core_v4/bulletin.py`) |
| **Bulletin Watermark** | A durable, non-prunable SQLite record tracking the highest admitted `revision`, pinned `publisher_pubkey`, `title`, and `content_hash` for a `bulletin_id` to prevent stale replay or key/title takeover after display pruning. | `bulletin_watermarks` SQLite table, `TFPNode._check_watermark`, `TFPNode.get_bulletin_watermark` (`tfp_core_v4/node.py`) |
| **Content-Defined Chunk (FastCDC)** | A boundary-shift-resistant byte slice (`512B`–`8KB`) produced by a 256-entry 64-bit gear rolling hash so insertions do not invalidate downstream chunks. | `ContentDefinedChunker` (`tfp_core_v4/chunker.py`), `MediaStreamPackager` (`tfp-foundation-protocol/tfp_client/lib/media/stream_packager.py`) |
| **Recipe Store** | The persistent mapping from a content/bulletin identifier to its ordered list of SHA3-256 chunk hashes and Merkle root, decoupled from reader chunk-size settings. | `recipes` SQLite table, `TFPNode.publish` / `TFPNode.fetch` (`tfp_core_v4/node.py`) |
| **Fountain Droplet** | A self-describing erasure-coded symbol packet carrying a PRNG seed (or systematic index), chunk metadata `(session_id, chunk_index, k)`, XORed payload bytes, and authentication tag/Merkle proof for rateless reconstruction over lossy channels. | `FountainDroplet` (`tfp_core_v4/fountain.py`), `MediaDropletPacket` (`tfp-foundation-protocol/tfp_client/lib/media/fountain_streamer.py`) |
| **Bell 202 AFSK Frame** | An audio-modulated physical frame using 1200 Hz (Mark) and 2200 Hz (Space) frequency-shift keying at 1200 or 300 baud with CRC-16 integrity checks for analog radio and acoustic speaker-to-microphone links. | `AFSKModulator` / `AFSKDemodulator` (`tfp-foundation-protocol/tfp_client/lib/audio/afsk_modem.py`), `TfpAfskCaptureProcessor` (`tfp-foundation-protocol/tfp_demo/static/acoustic_worklet.js`) |
| **Receiver Trust State** | The four-state cryptographic classification assigned to an incoming bulletin at the receiver boundary: `trusted_publisher`, `valid_signature_unknown_key`, `unsigned`, or `invalid_signature` (rejected/quarantined). | `verification_status` (`tfp_core_v4/bulletin_identity.py`), `acoustic_stream.js` (`tfp-foundation-protocol/tfp_demo/static/acoustic_stream.js`) |
| **Packaged Article Bundle** | A compressed, chunked client-side media/article archive prepared for streaming or static ingest before node bulletin registration. | `PackagedArticleBundle`, `ArticlePackager` (`tfp-foundation-protocol/tfp_client/lib/ingest/article_packager.py`) |
